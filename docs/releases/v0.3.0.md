# Nest Climate Monitor v0.3.0

First public prerelease for personal use. Download **NestClimateMonitor-v0.3.0.apk** below and install it on Android 10 or newer. No Play Store account or middleman server is required.

## Features

- Read-only Nest temperature and humidity monitoring, with outdoor weather from Open-Meteo.
- Local reading history, daily charts and min/max/average summaries.
- Resizable home-screen widgets, including a six-hour graph and transparent/borderless options.
- Humidity alerts, sampling diagnostics and CSV import/export.
- Requested 15-minute background sampling through Nest Device Access. Android can delay jobs; exact timing is not guaranteed.

## Setup and limitations

Follow the [README setup instructions](https://github.com/BenK22/NestClimateMonitor#readme). You must supply your own Google project and OAuth credentials in the app; none are bundled.

- **Nest Device Access:** Google charges a one-time **US$5** registration fee. This source supports background readings with the screen off or locked.
- **Weekly reconnection:** With an OAuth consent screen in Testing, Nest authorization commonly expires after about seven days. Repeat **Settings → Nest Device Access → 3. Connect Nest**. You do not need to recreate your project or rotate credentials just for this renewal.
- **Optional Google Home source:** Requires the phone to be unlocked with the screen on. Configure its Android OAuth client for package `ca.humiditylogger` with the release certificate SHA-1 listed below.

## Existing debug installations

This APK has a permanent release signature, different from development/debug builds. **Export readings before uninstalling a debug build.** Then install this APK, import your CSV and reconnect Google. Uninstalling removes app settings and credentials. Future official release updates use the same signing key and can preserve app data.
