# Nest Climate Monitor v0.4.0

Personal-use prerelease for Android 10 or newer. Download **NestClimateMonitor-v0.4.0.apk**
and its `.apk.sha256` checksum below. This remains an independent, read-only project, not an
official Google/Nest product or a universally tested production app.

## What's new

- Open-source library notices in **Settings → About → Open-source licenses** in release builds.
- Expanded setup, architecture, troubleshooting, privacy/security and contribution documentation.
- Automated Android verification for contributors without the Google Home SDK.
- Reviewed build-input hashes/action pins and safer SDK installation and release packaging.
- APK builds avoid unused Play-only encrypted dependency metadata while keeping license notices.

Temperature/humidity history, outdoor comparison, widgets, alerts and scheduling retain the
v0.3.0 behavior. No new backend or credentials bundled in the APK.

## Installation and setup

Official v0.3.0 installations can update in place: this release uses the same signing key and a
higher version code. **Developer/debug installations use another key.** Export CSV before any
manual uninstall/migration, then reconnect Google after installing the official release. Never
uninstall a working app just to test this release.

Follow the [README](https://github.com/BenK22/NestClimateMonitor#readme). Each user supplies their
own Google project/OAuth credentials. Device Access registration costs a one-time **US$5**;
OAuth apps in Testing generally need Nest authorization renewed after about seven days through
**Settings → Nest Device Access → 3. Connect Nest**. Existing saved client/project values remain valid.

Device Access supports screen-off/locked background requests. Google Home is an optional source
attempted only while the screen is on and the phone unlocked. Android may delay the requested
15-minute interval; exact timing is not guaranteed. Outdoor readings are Open-Meteo model estimates.

## Validation and remaining limitations

Full-SDK unit/lint/build checks and signed-APK checks are recorded in
[the validation record](https://github.com/BenK22/NestClimateMonitor/blob/main/docs/VALIDATION.md).
SDK-free CI does not validate Google's Home SDK or an individual account setup. Separate-account
onboarding and grant renewal remain open manual tests; broader thermostat/launcher compatibility
and overnight battery/scheduling behavior are not established across devices. Prerelease status
reflects these limits. Generated license notices do not waive third-party SDK/API terms.
