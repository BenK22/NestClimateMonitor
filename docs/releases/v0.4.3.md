# Nest Climate Monitor v0.4.3

Personal-use prerelease for Android 10 or newer. Download **NestClimateMonitor-v0.4.3.apk**
and its `.apk.sha256` checksum below. This is an independent, read-only project, not an
official Google/Nest product.

## What's new

- **No more freezes.** With Nest Device Access connected, every dashboard refresh decrypted the
  saved token through Android Keystore once per stored reading — hundreds of secure-hardware calls
  on the UI thread, slower still under Battery Saver. Those calls are gone, and dashboard loading,
  Settings counts, delete-all and widget rendering now run in the background.
- **Settings closes promptly** and taps no longer queue up behind a frozen screen.
- **Background sampling no longer blocks the screen.** The app, widgets and sampler share one
  database connection pool with write-ahead logging.
- **Scrolling works from the chart.** Up/down drags that start on the daily chart scroll the page;
  sideways drags and taps still move the crosshair.
- **Widget and alert taps reopen the same dashboard** instead of stacking a new copy each time.
- Hardening: the widget-setup screen only accepts this app's own widgets, the clipboard is cleared
  after importing the Google authorization URL, links no longer crash when no browser is available,
  and each CSV export removes older cached exports.

Sampling schedules, connections, saved readings and settings are unchanged.

## Installation and setup

Official releases use the same permanent signing key; this APK has versionCode 7 and installs as
an update over the official v0.4.2 APK. **Developer/debug installations use a different key.**
Never uninstall a working app merely to test an official release. Export CSV before any
intentional migration and reconnect Google after switching signing identities.

Follow the [README](https://github.com/BenK22/NestClimateMonitor#readme). Each user supplies their
own Google project/OAuth credentials. Device Access registration costs a one-time **US$5**.
OAuth apps in Testing generally need Nest authorization renewed after about seven days in
**Settings → Nest Device Access → 3. Connect Nest**; saved client/project values remain valid.

Device Access supports screen-off/locked background requests. Google Home is attempted only
while the screen is on and the phone unlocked. Android may delay the requested 15-minute
interval; exact timing is not guaranteed. Outdoor readings are Open-Meteo model estimates.

## Validation and limitations

The changes were exercised as a developer-signed update on the maintainer's Pixel 9a (Android 17)
with Battery Saver on and the battery at 25%: cold start, chart scrolling and crosshair, rapid
Settings toggles, Refresh now during scrolling, and graph-widget launches, with no ANR, crash,
database-lock or skipped-frame log entries. Existing readings and settings were retained.
The official APK's signer, version, non-debuggable state and license resources are checked
separately during packaging. See
[the validation record](https://github.com/BenK22/NestClimateMonitor/blob/main/docs/VALIDATION.md).

The official signed APK was not installed on the maintainer's phone, which runs a developer build.
Separate-account onboarding, an official APK-to-APK update test, overnight sampling/recovery and
broader thermostat/launcher compatibility remain unverified. This remains a prerelease.
