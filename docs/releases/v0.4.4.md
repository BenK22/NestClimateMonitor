# Nest Climate Monitor v0.4.4

Personal-use prerelease for Android 10 or newer. Download **NestClimateMonitor-v0.4.4.apk**
and its `.apk.sha256` checksum below. This is an independent, read-only project, not an
official Google/Nest product.

## What's new

- **Easier Nest permission renewal.** Once setup has succeeded, an expired/revoked refresh grant
  opens a focused renewal screen using the saved setup. The temperature/humidity widget shows
  **Token expired · Tap to renew**, and tapping it opens renewal. Normal automatic access-token
  refreshes and temporary network errors do not trigger this prompt; Google Home is independent.
- **An always-visible X close button** on the connection screen returns to history without
  deleting credentials or readings, including after scrolling the form.
- **Sampled equipment activity on graphs.** Heat, Cool and Off symbols mark actual indoor
  temperature samples in daily and widget graphs. Unknown is shown only when the plotted data
  needs it. Tap daily history for the state and associated sample time.
- **Selected-mode backgrounds.** Heat, Cool, Heat/Cool and Off settings shade daily/widget graphs
  separately from equipment activity. The last recorded mode continues across sampling gaps
  until the next recorded change; switch times are approximate, not exact event history.

Existing recorded modes/activity are used automatically. Missing modes remain unshaded; unknown
activity is not assumed Off. Raw values remain in the database and CSV backups. These are sampled
observations: short heating/cooling cycles between samples may be missed.

Opening the app, closing renewal and tapping a widget do not request a climate sample or reset
the periodic schedule. Use Settings → Refresh now for an explicit sample.

## Installation and setup

Official releases use the same permanent signing key. Version 0.4.4 has versionCode 8 and is
intended to update the official v0.4.3 APK. **Developer/debug installations use a different key.**
Never uninstall a working app just to test this release. Export CSV before an intentional signing
identity migration and reconnect Google afterwards.

Follow the [README](https://github.com/BenK22/NestClimateMonitor#readme). Users supply their own
Google project/OAuth credentials; none are bundled in the APK. Nest Device Access requires Google's
one-time US$5 registration. Testing-mode Nest grants commonly need renewal after about a week.
Approve access, copy the final Google URL back to the app, then complete the token refresh; saved
project/client settings do not need to be recreated.

Device Access supports screen-off/locked background requests. Google Home is attempted only
while the display is on and the phone unlocked. Android may defer the requested 15-minute interval.
Outdoor readings are Open-Meteo model estimates, not a sensor at the selected address.

## Validation and limitations

The feature code passed 88 JVM tests and 34 isolated device tests on the maintainer's Pixel 9a
(Android 17), including renewal routing, close-button scrolling/dismissal and widget expiry status.
Live renewal routing and the Nova widget's warning/tap were also checked. Compatible development
updates retained readings, the renewed connection and saved settings. Packaging verifies the
official signer's certificate, version, non-debuggable state and generated license resources.
See [the validation record](https://github.com/BenK22/NestClimateMonitor/blob/main/docs/VALIDATION.md)
for exact checks and their scope.

The official APK has not been installed over the maintainer's differently signed development app.
Separate-account onboarding, an official APK-to-APK upgrade test, overnight recovery and broader
thermostat/launcher compatibility are not established by these checks. Existing maintainer waivers
and known warnings remain in effect. This remains a prerelease.
