# Screenshots

The README gallery uses these user-supplied screenshots of Nest Climate Monitor:

- `dashboard.png`: indoor/outdoor readings, sample status, dew point, and daily history.
- `daily-history.png`: chart legend, daily min/max/average summaries, and thermostat state.
- `settings-connections.png`: setup, indoor sources, thermostat selection, and logging.
- `settings-data.png`: display preferences, outdoor location, alerts, and CSV backup/restore.

The selected thermostat's private device identifier is redacted in the history screenshot. Images contain no credentials or private street addresses. Keep only reviewed, publishable copies here.

## Screenshot checklist

Before publishing a release, capture current phone screenshots showing:

1. the portrait dashboard with indoor/outdoor readings and daily summary;
2. the landscape graph;
3. the current-readings widget at 2×1, 4×1, and 4×2;
4. the graph-only widget in transparent mode; and
5. Settings with no addresses, account names, notification contents, or other private information visible.

Store optimized PNG or WebP files here and link them from the main README.
